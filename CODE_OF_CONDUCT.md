# Code of conduct

## Our pledge

Everyone participating in this repository — maintainers, contributors,
commenters, and readers who ask questions — deserves a harassment-free
experience. We commit to making participation in this project a respectful,
professional, and technically serious environment.

## Expected behavior

- Be technically substantive: ask and answer questions about evidence,
  methods, and claims.
- Assume good faith disagreement about technical matters; that is what the
  course's epistemics chapters teach.
- Accept correction gracefully, and offer it with sources.
- Respect reviewers' and maintainers' time; keep issues minimal and
  reproducible.

## Unacceptable behavior

- Harassment, personal attacks, discriminatory comments about any personal
  characteristic, or sustained disruption of discussion.
- Sexualized language or imagery.
- Publishing or threatening to publish others' private information.
- Any conduct that would be considered unacceptable in a professional
  workplace.

## Enforcement responsibilities

Maintainers clarify standards of acceptable behavior and take appropriate,
fair corrective action in response to any instance of unacceptable behavior,
ranging from a warning to a ban from the repository's spaces.

## Reporting and contact route

Private vulnerability reporting is currently **not enabled** on this
repository, so reports should go through GitHub's verifiable contact route:
contact **@AdilShamim8** (the repository owner) via a GitHub mention in a
public issue only if the report itself is non-sensitive; otherwise use
GitHub's direct message / profile contact mechanism for the account. Do not
send reports to any email address you find in forks or web caches — this
repository publishes no email address, so any address claiming to be ours is
not ours.

All reports are reviewed and investigated confidentially where the platform
allows. Reporters are not required to identify themselves beyond what GitHub
requires to communicate.

## Scope

This code of conduct applies in all repository spaces (issues, PRs,
discussions) and applies to anyone acting as a project representative.
