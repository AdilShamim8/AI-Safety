# Crosswalk — the NIST AI RMF and the EU AI Act

*Part of the [Safeshield governance companion](README.md) · 2026-10-27*

The transatlantic pair: a framework without legal force that became
infrastructure, and a statute with full force still being stood up.

| Dimension | NIST AI RMF | EU AI Act |
|---|---|---|
| Instrument type | Voluntary risk-management framework | Binding horizontal regulation |
| Trigger of duties | Adoption (self-chosen; procurement-driven in practice) | Placing on the EU market / putting into service |
| Risk architecture | Risk functions across the lifecycle (G/MM/M) | Risk tiers by use case (prohibited / high / limited / minimal) |
| Core obligations | None (functions and suggested actions) | Documentation, data governance, logging, oversight, conformity assessment (high risk); transparency (limited) |
| GPAI coverage | Via the Generative AI Profile (voluntary) | Dedicated chapter with duties for all GPAI providers + a systemic-risk tier |
| Enforcement | None directly (reputation, procurement) | Member-state authorities; administrative fines |
| Timeline | Living framework (profiles evolve) | Staged application 2024–2027 |

**Where they interlock.** The Act's harmonized-standard work borrows
RMF vocabulary; US organizations serving EU markets run the RMF
process to produce the documentation the Act demands. The practical
translation table — which RMF artifact satisfies which Annex IV
requirement — is the compliance consultant's bread and butter, and
the honest version acknowledges the mapping is still moving (the
repo's register prices the Act's timeline page as perishable
exactly for this reason).
