## Where this lesson sits

The chapter's final scenario game: design a risk assessment for a fictional organization — tier the system, choose the checks, set the cadence — the chapter-two capstone.

## The concepts this exercise tests

### 1. Assemble the whole chapter

The game requires: the four steps in order (with stakeholder input), the EU tier classification with its duties, the internal checks set from the assessment's results (bias testing, behavior monitoring), and the culture posture — vigilance, not box-ticking. Each round scores one of these; the full run is the chapter in one playable pass.

### 2. The enclave's lesson

An enclave is a protected space with a purpose — the game's claim is that assessment design is exactly that: a constructed, guarded procedure that produces trust as its output. The repo's assurance chapter is the formal version of the same claim.
