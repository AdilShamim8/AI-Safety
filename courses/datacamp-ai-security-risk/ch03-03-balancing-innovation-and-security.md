# 3.03 — Balancing innovation and security

*Course companion note · [AI Security and Risk Management](README.md) ·
lesson 3 of chapter 3 (interactive exercise, 50 XP) · [course page](https://app.datacamp.com/learn/courses/ai-security-and-risk-management)*

## Where this lesson sits

The drill for the spectrum: position decisions on the innovation–security line and read the consequences for risk management.

## The concepts this exercise tests

### 1. Position determines response

Companies tending toward the innovation end accept and manage risk differently from those tending toward security — the video's rule that the position directly impacts how identified risks are managed. The exercise tests the inference both ways: from position to management style, and from management style back to position.

### 2. The compromise is always there

The video is explicit: there is ALWAYS a compromise between pursuing innovation and ensuring security. Exercise answers claiming a position escapes the compromise (innovation with no security cost, security with no agility cost) are the marked-wrong ones — the honest answer names both prices.
