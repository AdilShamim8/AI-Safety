# The beginner selection — the corpus from zero

**Navigate:** [← selections](README.md) · [START_HERE](../START_HERE.md)

**What this selection is.** The curated path for the reader who has
never run an evaluation, never read a paper, or never touched the
tooling — the corpus's on-ramp, ordered so that each step uses only
what earlier steps built.

## The path, in order

1. **Orient (hours).** [START_HERE](../START_HERE.md) then the
   [FAQ](../FAQ.md); the [prerequisites diagnostic](../prerequisites/diagnostic.md)
   diagnostic tells you which refreshers to run first — that page
   exists precisely so beginners skip nothing and waste no time.
2. **The spine (weeks).** The 24 chapters in order — the course is
   written to be linear; [Ch.01](../chapters/01-risk-models-and-research-epistemics/README.md)
   assumes nothing. Use the [study schedules](../roadmaps/study-schedules.md)
   to pick a pace.
3. **First artifact (one week).** [P01](../projects/p01-evaluation-harness/README.md)
   — the projects are deterministic and stdlib-first by design, so a
   beginner can run them on anything; the
   [example report](../projects/p01-evaluation-harness/example-report.md)
   shows what "done" looks like.
4. **The method (ongoing).** The [research method](../research/research-method.md)
   and the honesty discipline: every result with its interval, every
   claim with its access level.
5. **Then choose.** The [careers index](../roadmaps/careers-index.md)
   for direction; the [interview selection](interview-selection.md)
   when the goal is an offer; the [security](security-selection.md)
   or [safety](safety-selection.md) selections when the goal is a
   family.

## What this selection assumes

Nothing beyond the prerequisites page's own diagnostic — and honesty
about where you start. The corpus's whole method survives a beginner:
run the thing, measure it, state what you did not run. That sentence
is the on-ramp; everything else is practice.
