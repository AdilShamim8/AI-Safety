## 1. Identity and provenance

- **What it is:** a benchmark of real-world, economically valuable
  tasks — occupational task samples built to estimate what fraction
  of economic activity current AI systems can, in principle,
  automate. The capability-measurement companion to the
  economics-of-AI debate (and the artifact Harvard CS 2881's closing
  lecture is named for).
- **Canonical home:** the [openai/gdpval repository](https://github.com/openai/gdpval)
  [R2]. Paper: *GDPval: Evaluating AI Model Performance on
  Real-World Economically Valuable Task*, arXiv:2510.04374,
  2025-10-05 [R1] — title/authors/date verified via the arXiv API on
  2026-10-27.
- **Authors (API-verified [R1]):** Tejal Patwardhan, Rachel Dias,
  Elizabeth Proehl, Grace Kim (OpenAI).
- **How WE obtained it:** arXiv API title-match + repository page
  inspection on 2026-10-27; no task content downloaded or redistributed.

## 2. Composition (abstract-level)

- Task samples drawn from real occupations, weighted toward
