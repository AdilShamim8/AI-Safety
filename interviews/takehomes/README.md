# The take-homes — six formats, projects you can already run

**Navigate:** [← interviews](../README.md) · [questions](../questions/README.md)

**What this sub-layer is.** The take-home round, decoded: six formats
that cover what teams actually issue, each mapped to a project this
repository already implements — so practice is running the corpus,
and the corpus is the practice.

| Format | Maps to | The trick |
|---|---|---|
| [Harness build](harness-build.md) | P01 | report what an auditor needs, not what a demo shows |
| [Defense fix](defense-fix.md) | P07 | the not-covered list IS the assignment |
| [Audit format](audit-format.md) | P04 + P09 | decompose before judging |
| [Dossier](dossier.md) | P10 | the whole pipeline in one honest document |
| [Governance](governance-flavored.md) | the standards spine | instruments separated by layer, dates with claims |
| [Mini-study](mini-study.md) | P06 | preregister, control, attempt to falsify |

**The habit all six reward.** Every format ends the same way: what
was run, what was not, and the pinned result. Take-homes are graded
by senior readers who have been burned by confident demos; the
not-covered list is how they tell the difference.
