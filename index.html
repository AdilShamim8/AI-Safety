02 The judge's instrument — how information gets in

The verification protocol every source passes

Nothing is trusted because it is famous. The method, applied uniformly:

  1. Fetch the primary source — the arXiv abstract page, the canonical repo, the license file — never a memory of it, and record the access level honestly.
  2. Register the claim, not the vibe — every number lands in the claims register with a falsifiable statement, assumptions, and counterevidence.
  3. Price the weakness — vendor-published figures, self-reported outcomes, and dated snapshots are marked as exactly that, in the prose and in the register.
  4. Keep the audit trail hot — the missing-values audit and repo validator run in CI; every cross-reference (SRC-*/CLM-*) in 134 markdown files is machine-checked.
